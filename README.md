# Minimizing_Carbon_Footprint_Using_Algal_Serpentine_Tubular_Photobioreactor
With rising CO₂ from steel &amp; power plants, this project builds a serpentine photobioreactor where microalgae grow by fixing CO₂ into biomass. Instead of waste, the biomass becomes pharma &amp; biofuel feed. A working model is testing CO₂ levels to maximize yield, making the idea green, useful &amp; future-ready.
